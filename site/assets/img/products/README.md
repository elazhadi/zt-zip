# Photos produits — mode d'emploi

Le site affiche automatiquement une **illustration SVG** par défaut. Dès que
vous déposez une vraie photo avec le bon nom de fichier dans ce dossier, elle
remplace l'illustration **sans aucune modification de code** (repli automatique
via `onerror`).

## Fichiers attendus

Placez ici des images (idéalement **1200 × 800 px**, format paysage, `.jpg`) :

| Fichier              | Utilisé pour                                  |
|----------------------|-----------------------------------------------|
| `coulissant.jpg`     | Systèmes coulissants (accueil + produits)     |
| `battant.jpg`        | Systèmes battants (accueil + produits)        |
| `porte.jpg`          | Portes & blocs-portes ALUDOORS                |
| `mur-rideau.jpg`     | Mur rideau / façades                          |
| `accessoires.jpg`    | Accessoires & quincaillerie (accueil)         |

## Où trouver les photos officielles

En tant que **distributeur agréé STRUGAL**, vous pouvez utiliser les visuels
du catalogue et de la médiathèque officielle :

- Site officiel : https://www.strugal.com (rubriques systèmes)
- Catalogue Strugal Maroc : https://www.strugal.ma
- Chaîne YouTube (captures possibles) : https://youtube.com/@strugalaluminium

> ⚖️ Utilisez de préférence les fichiers fournis par STRUGAL à ses distributeurs
> (kit média / catalogue) afin de respecter les droits d'usage des images.
> Évitez de pointer directement vers des images hébergées sur strugal.com
> (liens susceptibles de casser) : téléchargez-les puis déposez-les ici.

## Conseil

Compressez les images (TinyPNG, Squoosh…) pour garder un site rapide :
visez moins de ~250 Ko par photo.
